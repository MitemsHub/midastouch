# V75 (1s) @ H1 TUNING PROTOCOL — frozen 2026-09-15 before any run

**Question:** the shipped config on V75(1s)@H1 earned the only SCAN pass
of the cross-symbol matrix (+10.51R IS, n=406). Can a bounded parameter
search on its IS window produce a candidate that survives OOS?

**Data:** artifacts/train/v75low_h1 (H1-primary, 24,017 bars,
2023-11-06 → 2026-09-15). IS 2023-12-01 → 2026-06-01 (search);
OOS 2026-06-01 → 2026-09-15 (validation). Touch fills, equity 300,
risk 0.005, auto-disable ON, V75(1s) spec (spread 1.90, $1.0/unit/lot,
min lot 0.05, step 0.001), spec constants set BEFORE lab import.

  {0.9, 1.0, 1.15} × be_trigger {0.8, 1.0, 1.2} × plock_z {0.4, 0.5, 0.6}.
  Base config otherwise = shipped (no ema_side, no gates, MR/BF/MOM as

  excluded after Amendment C showed they do not transfer to this symbol).

## 2. Selection (frozen)

Eligibility: n ≥ 150, totalR > 0, DD ≤ 25%, streak ≤ 10, WR ≥ 45%
(n bar higher than V75's: this symbol's IS edge lived at n≈400; a
tuned config that trades < 150 times is not the same edge). Rank by
totalR; tie-break n, then DD. **Finalists: top 2.**

## 3. Fresh OOS gates (pre-registered, with multiplicity levy)

OOS has been touched twice before (original scan, Amendment C); every
OOS statistic is discounted accordingly:
1. n ≥ 30,
2. totalR > 0 **+ 2.0R levy** (twice the standard 1.0R margin: the
   window's prior exposure demands a larger beat over noise),
3. DD ≤ 25% (stricter than the standard 30%),
4. meanR ≥ 60% of IS meanR (degradation bound, stricter than 50%),
5. **split-OOS robustness: both halves (Jun 1–Jul 23, Jul 24–Sep 15)
   individually non-negative.** A candidate that only wins one half is
   a coin, not a config.
6. IS preservation: IS totalR ≥ +8R (the tuning must not destroy the
   edge it tuned).

SHIP requires ALL six, on at least one finalist. Everything else is
NO-SHIP and the shipped-at-scale config stands.

## 5. Results (filled after the runs)

**Search:** stage 1 = 108 runs (88 s), 7 eligible; stage 2 = 18 runs,
11 eligible. Finalists (frozen rule): tp **2.4** / sm 1.0 / pz **0.6** /
shipped PB band, be 1.0 and 1.2 (twins: IS +20.44R / +20.37R, n=429,
DD 24.6%, streak 9). The tuning's IS gain over the shipped config
(+20.4 vs +10.5) came from two moves: TP 1.8→2.4 and PLOCK 0.5→0.6.

**OOS (fresh gates, one pass):**

| gate | F1 (= F2 twin) |
|---|---|
| g1 n ≥ 30 | PASS (53) |
| g2 totalR > +2.0R levy | **FAIL (−6.87R)** |
| g3 DD ≤ 25% | **FAIL (37.4%)** |
| g4 meanR ≥ 60% IS | **FAIL** |
| g5 split halves ≥ 0 | **FAIL (+2.74 / −5.63)** |
| g6 IS preserved ≥ +8R | PASS (+20.44) |

Shipped-baseline OOS on the identical window: −3.97R.

**Verdict: NO-SHIP.** The tuned config is *worse* out-of-sample than the
config it tuned (−6.87 vs −3.97): the +10R IS gain was curve-fit, and
both tuning moves are individually suspect — TP 2.4 is the legacy
multiple whose V75 history is the walkforward inversion itself, and
PLOCK 0.6 harvests 0.6R gains that the OOS bull regime would have run
further. The split halves localize the failure to the late window
(+2.74 Jun–Jul, −5.63 Jul–Sep) — the same late-window bleed every
candidate has shown on every symbol. The shipped config stands on this
symbol too; the forward test remains the only clean judge left.
